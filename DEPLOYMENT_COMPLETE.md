## 📞 TROUBLESHOOTING

### **"Node is not installed"**
→ Download from nodejs.org, install, restart terminal

### **"Git is not installed"**
→ Download from git-scm.com, install, restart terminal

### **"Build failed"**
→ Check error message, usually tells you what's wrong
→ Run: `tsc --noEmit` for detailed error

### **"Stripe payment not working"**
→ Check API keys are LIVE mode (not TEST mode)
→ Verify keys are in .env.production

### **"Analytics not tracking"**
→ Check GA ID is correct (G-XXXXXXXXXX format)
→ Check it's in .env.production
