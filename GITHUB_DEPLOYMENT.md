## **STEPS TO DEPLOY:**

### **Step 1: Build Your Code (1 minute)**
```
1. Double-click: BUILD_ONLY.bat
2. Wait for: ✓ Build successful!
3. Close the window
```

You'll now have a `dist/` folder with your website files.

---

### **Step 2: Go to Your GitHub Repo**
```
Go to: https://github.com/whoamiharshh/dist
```

---

### **Step 3: Upload Files**

#### **Option A: Upload via GitHub Web (Easiest)**
```
1. Click: "Add file" button (top right)
2. Select: "Upload files"
3. Drag dist/ folder contents here
4. Scroll down
5. Click: "Commit changes"
```

#### **Option B: Using Git CLI (Faster)**
```
1. Open Command Prompt
2. Type: cd C:\Users\Sir\Desktop\website
3. Type: git init
4. Type: git add dist/*
5. Type: git commit -m "Deploy website"
6. Type: git remote add origin https://github.com/whoamiharshh/dist.git
7. Type: git push -u origin main
```

---

### **Step 4: Enable GitHub Pages**

```
1. Go to: https://github.com/whoamiharshh/dist
2. Click: "Settings" (top right)
3. Click: "Pages" (left menu)
4. Under "Build and deployment"
5. Select: "Deploy from a branch"
6. Branch: "main"
7. Folder: "/ (root)"
8. Click: "Save"
9. Wait 2-3 minutes
10. Your URL appears: https://whoamiharshh.github.io/dist
```

---

### **Step 5: Visit Your Live Website**

```
Go to: https://whoamiharshh.github.io/dist
See: YOUR LIVE WEBSITE! 🌍
```

## **DETAILED UPLOAD INSTRUCTIONS:**

### **Step by Step via GitHub Web UI:**

```
1. Go to: https://github.com/whoamiharshh/dist

2. Click: "Add file" dropdown (near Code button)

3. Select: "Upload files"

4. You'll see: "Drag files here to add them to your repository"

5. Find your dist/ folder:
   Location: C:\Users\Sir\Desktop\website\dist
   
6. Open File Explorer to that folder

7. Drag ALL FILES from dist/ to GitHub upload area
   (Don't drag the dist folder itself, drag the contents)

8. Scroll down

9. Under "Commit changes":
   - Message: "Add website files"
   - Select: "Commit directly to main branch"

10. Click: "Commit changes"

11. GitHub will upload everything

12. Wait ~1 minute for upload to complete
```

## **ENABLE GITHUB PAGES:**

```

   "Build and deployment"

7. Select: "/ (root)" folder

8. Click: "Save"

9. Wait 2-3 minutes

10. GitHub will show:
    "Your site is live at: https://whoamiharshh.github.io/dist"
```
