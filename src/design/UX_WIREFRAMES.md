## Key UX Principles

1. **Linear but non-blocking** - Users follow a clear path but can skip steps
2. **Progress visibility** - Always show what the AI is doing
3. **Cinematic pacing** - Smooth transitions between states
4. **Mobile-first responsive** - Works perfectly on all devices
5. **Accessibility** - Clear labels, good contrast, keyboard navigation
6. **Performance first** - Async rendering, lazy loading, streaming responses
7. **Error resilience** - Graceful failures with recovery options
8. **Premium feel** - Elegant spacing, smooth animations, polished interactions
